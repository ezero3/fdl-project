# WM-811K Split Artifacts

These files are generated by `notebooks/02_split_data.ipynb` with random seed 86. They store row indices into `data/MIR-WM811K/WM811K.pkl`; the wafer-map arrays are not duplicated.

## Supervised subsets

- `train_indices.npy`: labeled training observations;
- `validation_indices.npy`: labeled validation observations;
- `test_indices.npy`: frozen labeled test observations;
- `labeled_split_manifest.csv`: row index, lot, class, native split, and new split membership;
- `class_counts.csv`: supervised class counts by subset.

## Unlabeled observations

- `unlabeled_indices.npy`: all unlabeled observations;
- `unlabeled_train_eligible_indices.npy`: unlabeled observations allowed in future training-only SSL or pseudo-labeling;
- `unlabeled_excluded_indices.npy`: unlabeled observations associated with validation or test lots and therefore excluded from training;
- `unlabeled_role_counts.csv`: counts for each unlabeled role.

Load a subset without copying the full dataset:

```python
import numpy as np
import pandas as pd

dataset = pd.read_pickle("data/MIR-WM811K/WM811K.pkl")
train_indices = np.load("data/splits/train_indices.npy")
train_data = dataset.loc[train_indices]
```

Do not regenerate or modify these artifacts independently for different models. All pipelines must reuse the same split.
